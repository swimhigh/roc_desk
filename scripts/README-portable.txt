roc_desk 便携版使用说明

一、产品简介
roc_desk 是面向开发者的桌面工作区工具，集成文件管理、代码编辑、终端、SSH/SFTP、日志检索、网页浏览和 AI 助手。

二、主要功能
1. 工作区：支持本地目录和远程 SSH 目录；会按工作区隔离会话、编辑器标签和配置。
2. 文件管理：目录树浏览、文件新建、删除、重命名，并可快速打开文件。
3. 代码编辑：基于 Monaco Editor，支持语法高亮、多个文件标签、搜索和替换。
4. 终端：支持多个本地终端和远程 SSH 终端；打开工作区时默认不自动启动，点击“终端”后再启动。
5. SSH/SFTP：管理 SSH 连接，浏览远程目录并上传、下载和查看文件。
6. 日志搜索：对本地或远程日志进行关键词搜索，并支持定位结果。
7. AI工具：统一提供普通问答与编程能力；支持 Plan/Build 模式、工具执行过程展示、Markdown、文件引用、Diff 接受/拒绝/撤销和历史会话。
9. 网页浏览：在应用内打开网页并管理浏览历史。

三、便携运行
直接双击本目录中的 roc_desk.exe 即可运行；bin 目录中的 DLL（如有）需与 EXE 保持同级。
首次启动会在 EXE 旁创建 .rock_desk 目录，用于保存工作区信息、会话、编辑器状态和应用缓存。
将整个 bin 目录复制到其他 Windows 机器即可使用，不能只复制 EXE。

四、运行环境与安全
Windows 10/11 通常已预装 WebView2 Runtime；若启动失败，请安装 Microsoft Edge WebView2 Runtime。
API Key、SSH 密码等敏感信息不会写入 README；请勿将密钥直接提交到 Git 或复制给他人。
远程工作区需要网络可达，并正确配置 SSH 连接。
